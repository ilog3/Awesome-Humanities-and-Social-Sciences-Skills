## 1. 编程与数据科学基础 / Programming & Data Science

### Python 技能与库
* [pandas](https://github.com/pandas-dev/pandas) - 社科数据清洗、结构化数据分析的核心 Python 库。
* [BeautifulSoup4](https://www.crummy.com/software/BeautifulSoup/) & [Scrapy](https://github.com/scrapy/scrapy) - 抓取网络新闻、政府公告与社交媒体数据的必备爬虫工具。
* [JupyterLab](https://github.com/jupyterlab/jupyterlab) - 结合代码、文本与可视化的交互式科研笔记本。

### R 语言社科生态
* [tidyverse](https://github.com/tidyverse/tidyverse) - R 语言中专为数据科学设计的核心包集合（包含 ggplot2, dplyr 等）。
* [QSS (Quantitative Social Science)](https://github.com/kosukeimai/qss) - Kosuke Imai 教授编写的计算社会科学量化分析入门教程与代码库。

## 2. 文本挖掘与自然语言处理 / Text Mining & NLP

### 文本预处理与 OCR
* [dhSegment](https://github.com/dhlab-epfl/dhSegment) - 洛桑联邦理工学院开发的历史档案数字化与手稿图像分割工具。
* [tesseract](https://github.com/tesseract-ocr/tesseract) - 开源 OCR 引擎，支持多语言历史文献的文本提取。

### 主题模型与语义分析
* [BERTopic](https://github.com/MaartenGr/BERTopic) - 基于 Transformer 预训练模型的现代化主题建模工具，非常适合社科与人文文本。
* [quanteda](https://github.com/quanteda/quanteda) - 政治学与社科领域最流行的 R 语言定量文本分析框架。
* [topic-models-for-humanists](https://github.com/maria-antoniak/topic-models-for-humanists) - 专为人文社科研究者设计的 Topic Modeling 实用指南与代码。

## 3. 社会网络与空间分析 / Social Network & Spatial Analysis

### 网络分析 (SNA)
* [NetworkX](https://github.com/networkx/networkx) - 用于创建、操作和研究复杂网络结构的 Python 库（如人物关系网络、引用网络）。
* [Gephi](https://github.com/gephi/gephi) - 开源的复杂网络可视化与分析软件，数字人文领域广泛使用。

### GIS 与历史地理空间
* [QGIS](https://github.com/qgis/QGIS) - 功能强大的开源地理信息系统，支持历史地图比对与空间数据分析。
* [geopandas](https://github.com/geopandas/geopandas) - 将 pandas 扩展至地理空间数据的 Python 绘图与分析工具。

## 4. 高效学术工作流 / Academic Workflows

### 文献管理与笔记知识库
* [Zotero](https://github.com/zotero/zotero) - 强大的开源文献管理工具，支持丰富插件生态（如 Better BibTeX, Zotfile）。
* [Obsidian](https://obsidian.md/) - 基于 Markdown 的本地知识库工具，适合搭建人文社科卡片盒（Zettelkasten）笔记系统。

### Markdown, Quarto & LaTeX 学术写作
* [Quarto](https://github.com/quarto-dev/quarto-cli) - 新一代开源学术出版系统，支持无缝结合代码（R/Python）、文本与参考文献，直接导出 PDF/Word/HTML。
* [Pandoc](https://github.com/jgm/pandoc) - 学术文档格式转换的神器（Markdown/Word/LaTeX/PDF 自由互转）。
* [Academic Markdown Template](https://github.com/WillemMcConlogue/academic-markdown-template) - 基于 Pandoc 和 Zotero 的学术论文写作模板。

### 版本控制与可重复研究
* [Git & GitHub for Academics](https://github.com/planetcassini/git-for-academics) - 面向学术研究者的 Git 版本控制与协同写作入门教程。

## 5. Skill 技能库 / Skill Library

本仓库同时收录了**可直接迁移到 Agent 平台的 Skill 技能包**，存放于 [`skill-library/`](./skill-library/) 目录。

每个 Skill 为独立目录，包含 `SKILL.md`（YAML frontmatter：`name` / `category` / `description`），可直接打包为 `.zip` 上传到支持 Skill 的 Agent 平台（如 Inno Agent、OpenAgentHarness 等）。完整清单见 [`skill-library/README.md`](./skill-library/README.md)。

**三大分类概览：**

| 分类 | 数量 | 说明 |
|---|---|---|
| 研究检索 | 11 | 文献综述、证据校验、元分析、选题拆解、学者蒸馏等 |
| 教学辅导 | 10 | 研究设计（量化/质性/混合）、问卷开发、行动研究等 |
| 开发工具 | 9 | 数据清洗、描述/推断统计、信效度分析、质性编码等 |

## 7. 贡献指南 / Contributing

欢迎对本仓库进行补充和完善！如果你发现了优秀的工具、库或教程，请随时提交 Pull Request 或发起 Issue：

1. Fork 本仓库。
2. 创建你的特性分支 (`git checkout -b feature/AmazingSkills`)。
3. 提交你的修改 (`git commit -m 'Add some amazing skill/tool'`)。
4. 推送到分支 (`git push origin feature/AmazingSkills`)。
5. 发起一个 **Pull Request**。

请确保推荐的内容符合以下标准：
- 高度相关于人文社科（HSS）、数字人文（DH）或计算社会科学（CSS）。
- 项目开源、文档清晰或对学术研究有实质帮助。
