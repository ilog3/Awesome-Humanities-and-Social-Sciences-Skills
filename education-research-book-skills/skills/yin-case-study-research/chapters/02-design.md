# 案例研究设计

## Five components

1. research questions;
2. propositions, if any, or an explicit exploratory purpose;
3. case and unit(s) of analysis;
4. logic linking data to propositions;
5. criteria for interpreting findings.

Develop a preliminary theory that identifies expected mechanisms, context, and rivals. This supports **analytic generalization**: findings corroborate, modify, reject, or extend theoretical propositions rather than estimate a population.

## Four design types

|  | Holistic: one unit | Embedded: multiple units |
|---|---|---|
| Single case | Type 1 | Type 2 |
| Multiple cases | Type 3 | Type 4 |

Use an embedded design when meaningful subunits enable comparison. Guard against shifting the study entirely to subunits and losing the whole-case phenomenon.

## Single case rationales

A single case may be justified as critical for testing theory, unusual/extreme, common/typical, revelatory, or longitudinal. Document why it satisfies the rationale and remain alert to later evidence that invalidates the premise.

## Multiple-case replication

Select each case for:

- **literal replication:** predicted similar results;
- **theoretical replication:** predicted contrasting results for stated reasons.

Complete each case as a whole inquiry, then conduct cross-case synthesis. Do not select cases as if a small convenience set were a statistical sample.

## Design quality

- **Construct validity:** multiple sources, chain of evidence, key-informant review of draft case material.
- **Internal validity:** pattern matching, explanation building, rival explanations, logic models; relevant mainly to explanatory claims.
- **External validity:** theory and replication logic supporting analytic generalization.
- **Reliability:** protocol and database enabling consistent procedures.
