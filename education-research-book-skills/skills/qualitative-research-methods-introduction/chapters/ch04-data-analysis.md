# Data Analysis

## Recursive process

1. Securely organize, name, and inventory material.
2. Read or listen holistically and write first-impression memos.
3. Segment data without losing source context.
4. Open-code actions, meanings, relations, settings, and consequences.
5. Compare segments and cases; revise code definitions.
6. Connect categories, conditions, sequence, and variation.
7. Focus on an interpretive account while preserving alternatives.
8. Seek disconfirming evidence and return to raw material.
9. Write claims with representative evidence and boundaries.

Open, axial, and selective coding can help organize movement from detail to integration, but should not be imposed on traditions whose analytic object is narrative form, discourse, culture, or historical testimony.

Use matrices, timelines, diagrams, case summaries, domain analysis, hermeneutic part–whole reading, narrative structural analysis, constant comparison, or action-research reflection according to the question. Counting may clarify distribution inside qualitative material, but frequency does not establish significance.
